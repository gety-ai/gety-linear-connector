# Linear Connector for Gety

> [!IMPORTANT]
> This repository is archived. The connector is now developed in
> [gety-ai/gety-connectors](https://github.com/gety-ai/gety-connectors/tree/main/connectors/linear)
> and published on npm as
> [`@gety-connectors/linear`](https://www.npmjs.com/package/@gety-connectors/linear).

Install it in Gety 0.7.0 or later from **Settings → Connectors → Featured
connectors**. If you installed it from a release of this repository, delete it
in Gety first: both use the connector ID `linear`, so only one can be installed.
